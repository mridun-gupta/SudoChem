# 🤖 Digital Computation in Emerging Areas (AI/ML/DA)

> **Program:** *Integrated Masters of Technology in Chemical Technology*
> **Institution:** *Institute of Chemical Technology, Mumbai – Marathwada Campus, Jalna (MarJ, in short)*
> **Semester:** *4*

This folder contains explorations, experiments, and assignments related to **Artificial Intelligence**, **Machine Learning**, and **Data Analytics**. It's a sandbox for implementing algorithms, testing models, and understanding computational approaches to solving complex problems.

---

## 📂 Folder Structure

```
AIML/
├── data/                    # Input/output data files (Excel, CSV, etc.)

├── numpyDemo.ipynb          # NumPy array operations
├── pandasDemo.ipynb         # Pandas data structures and manipulation

└── README.md                # This file
```

## 📔 Notebooks

Contains Jupyter notebooks (.ipynb) exploring Python fundamentals, data manipulation, and computational methods.

**Notebooks in order:**
1. `pythonDemo.ipynb` - Python basics review
2. `pythonAssignment.ipynb` - Python assignment/coursework
3. `numpyDemo.ipynb` - NumPy array operations
4. `pandasDemo.ipynb` - Pandas data structures and manipulation
5. `importingData.ipynb` - Data import workflows

## 📊 Data

Stores data files used across notebooks in `data/` subfolder:
- `input.xlsx` - Base input dataset (used across all notebooks)
- `output_1.xlsx` - Pandas output from analysis
- `output_2.xlsx` - Pandas output from analysis
