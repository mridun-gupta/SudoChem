# Absorber Problem

## Objective

To design an absorber for removal of NH3 from NH3-CO2 gas mixture and determine:

- Number of theoretical plates,
- Location of plates,
- Height of tower

---

# Operating Conditions

| Parameter | Value | Unit |
|---|---:|---|
| Feed flow rate, `F` | 100 | kg/h |
| Temperature, `T` | 300 | K |
| Pressure, `P` | 1 | bar |
| Column diameter, `D` | 1 | m |
| Volumetric gas-phase coefficient, `Kya` | 20 | as supplied |

# Component / Composition Data

| Variable | Meaning | Value |
|---|---|---:|
| `yb` | Gas inlet NH3 mole fraction | 0.80 |
| `ya` | Gas outlet NH3 mole fraction | 0.10 |
| `xb` | Liquid outlet NH3 mole fraction | 0.70 |
| `xa` | Liquid inlet NH3 mole fraction | 0.20 |
| `MW_NH3` | Molecular weight of NH3 | 17.03 kg/kmol |
| `MW_CO2` | Molecular weight of CO2 | 44.01 kg/kmol |

# Equilibrium Data

```text
x = [0.10 0.20 0.30 0.40 0.50 0.60 0.70 0.80 0.90 1.00]

y = [0.01 0.05 0.10 0.17 0.26 0.36 0.47 0.60 0.74 0.90]
```

The equilibrium data are fitted to a third-order polynomial:

```text
y_eq = A*x^3 + B*x^2 + C*x + D
```

using MATLAB `polyfit`.

---

# Theory

## Column Area

```text
Area = pi*D^2/4
```

## Average Gas Molecular Weight

```text
MW_in  = yb*MW_NH3 + (1-yb)*MW_CO2
MW_out = ya*MW_NH3 + (1-ya)*MW_CO2
MW_avg = (MW_in + MW_out)/2
```

## Gas Molar Flow Rate

```text
G = F/MW_avg
```

## Operating Line

For the specified inlet and outlet compositions:

```text
y = m*x + c

m = (yb - ya)/(xb - xa)
c = ya - m*xa
```

## Equilibrium Composition

At a specified gas composition `y`, solve:

```text
A*x^3 + B*x^2 + C*x + D - y = 0
```

## HTU

```text
HTU = G/(Kya*Area)
```

## NTU

Using the gas-phase driving force:

```text
Driving force = y - y_eq

NTU = integral[dy/(y-y_eq)]
```

The code evaluates this integral numerically with `trapz`.

## Tower Height

```text
Z = HTU*NTU
```

---

# McCabe-Thiele Calculation

The stage calculation starts from the gas outlet/liquid inlet point `(xa, ya)`. The program moves horizontally to the equilibrium curve and then vertically to the operating line until the specified gas inlet composition `yb` is reached.
