# Result index

The canonical execution outputs are retained under `Python/results/` because the Python CLI writes there and uses unique run-directory names. This folder holds the Prompt 22 sensitivity/uncertainty studies and their logs under `Results/Sensitivity_Optimisation/`. Fresh-extraction Prompt 25 runs are identified in `QA/Fresh_Extraction_Test/run_log.txt` and retained as unique run folders under `Python/results/`.

All numeric values must be interpreted using the explicit status fields in `results.json`, run logs and the model validity documentation. The Prompt 22 OAT/LHS outputs are SCREENING ONLY and do not establish a plant operating window or physical optimum.
