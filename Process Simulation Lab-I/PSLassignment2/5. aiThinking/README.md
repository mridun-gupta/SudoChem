# ENERGY-008 Engineering Thinking Repository

This folder contains the research, calculation, report, design, verification and historical evidence associated with the ENERGY-008 MATLAB application. The top-level package contains exactly two folders: `MATLAB/` and `thinking/`.

## Primary deliverables

- `reports/final_release/ENERGY008_Comprehensive_Technical_Report_Rev1.1.docx` - editable Volume I.
- `reports/final_release/ENERGY008_Comprehensive_Technical_Report_Rev1.1.pdf` - Volume I PDF.
- `reports/final_release/ENERGY008_Detailed_Calculation_Book_Rev0.3.docx` - editable Volume II with native equation objects.
- `reports/final_release/ENERGY008_Detailed_Calculation_Book_Rev0.3.pdf` - Volume II PDF.
- `reports/final_release/ENERGY008_Comprehensive_Report_Set_Rev1.1.pdf` - combined 2-volume PDF with bookmarks.
- `presentation/final_release/ENERGY008_Short_Presentation_Rev1.1.pptx` - concise 12-slide deck.

## Organization

- `engineering_basis/`: assignment, design basis, configuration and source-document interpretation.
- `calculations/`: manual workings, registers, data dictionaries, sensitivity records and equation mapping.
- `reports/`: final report volumes plus original source reports and legacy registers.
- `sources/`: literature, case studies, standards, property data and raw datasets.
- `equipment/`, `design_documents/`, `control_environment_safety/`: equipment datasheets, process drawings, control and safety records.
- `results/`, `verification/`: numerical results, tests, audits, logs and QA records.
- `prompts/`, `python_migration/`, `archive/`: phase prompts/handoffs, Python migration source and historical evidence.

The source records are retained; Rev 0.2 and earlier project artifacts are not silently overwritten. The release manifest is in `verification/`.
