# Raw and controlled source snapshots

These files are immutable copies of named upstream phase deliverables. Subfolders group source artifacts by phase. The current Prompt 18 archive includes requirements and route/design-basis records from Prompts 1–3, property/data and model records from Prompts 5–6, process description/PFD/battery-limit records from Prompt 7, convergence algorithms and flowcharts from Prompt 16, and the manual calculation workbook, independent checks and fixture/report evidence from Prompt 17.

Their hashes, format declarations, source versions and discovery rules are recorded in `../data_manifest.json`. Do not edit files in place; create a new revision and update the manifest under change control. Historical Prompt 5 inventory entries do not grant permission to search outside this project's allow-listed roots.
