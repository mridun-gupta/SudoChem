# ENERGY-008 report layout and equation standard | Rev 1.1

The final report follows the uploaded report reference's A4 academic-engineering layout: Times New Roman body text, navy heading hierarchy, pale-blue table headers, controlled captions, section navigation, centred page numbering and appendices. Mathematical equations are typeset as editable Microsoft Word Math objects rather than screenshots.

- Volume I: `ENERGY008_Comprehensive_Technical_Report_Rev1.1.docx/.pdf` retains the original 27-topic assignment order and section-based equation numbers.
- Volume II: `ENERGY008_Detailed_Calculation_Book_Rev0.3.docx/.pdf` contains calculation cards and locally numbered editable equations, with the canonical HC calculation IDs preserved.
- The short presentation summarizes the basis, reference calculations, industrial case studies, limitations and engineering gates.

Equation and calculation IDs are cross-referenced from source registers. A source-derived number or arithmetically correct calculation is not promoted to physical-model validation without separate evidence.
