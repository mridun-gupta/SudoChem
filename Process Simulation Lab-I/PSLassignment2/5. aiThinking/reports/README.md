# Report Index

Canonical report files are stored in the root `Report/` directory for compatibility with existing links and audit records:

- `../../Report/ENERGY008_Technical_Report.docx` and `.pdf` - original 27-topic main technical report, Rev 1.0.
- `../../Report/ENERGY008_Detailed_Calculation_Book_Rev0.2.docx` and `.pdf` - supplemental calculation volume, 57 rendered pages.
- `../../Report/Figure_Register.csv` and `../../Report/Table_Register.csv` - main-report figure/table registers.

The calculation book adds HC-001 to HC-018, CAL-001 onward, EQ-001 to EQ-028, OAT/LHS records, source references and engineering hold points. It is a companion volume, not a replacement for the main report.
