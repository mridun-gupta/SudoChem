# Assessment of candidate open-source thermodynamics/process packages

**Assessment date:** 2026-11-02  
**Decision:** NumPy, SciPy, pandas and Matplotlib are the only installed project dependencies in this migration stage. CoolProp, Cantera, BioSTEAM and DWSIM are evaluated but not silently substituted for missing ENERGY-008 model data.

## Installation, compatibility and licence review notes

- The project stack was executed on CPython 3.13.5 / Linux x86_64. Optional property/process libraries below were **not installed or tested** in this migration release. No compatibility is inferred solely from an upstream Python API.
- **CoolProp 8.0.0** documents pure/pseudo-pure fluids, mixture Helmholtz models, IAPWS-IF97 water/steam and cubic PR/SRK/PC-SAFT backends. The upstream repository identifies MIT licensing. It is the most relevant optional property adapter, but the active PR78 binary-parameter matrix and independent ENERGY-008 mixture validation remain mandatory.
- **Cantera 3.2.0** provides thermodynamic, kinetic and transport models and Python interfaces. Official installation guidance recommends Conda for new installs, while pip installation is available. Its licence is BSD 3-Clause. It is relevant only after an approved catalyst mechanism and rate parameterisation are available.
- **BioSTEAM** documentation covers unit operations, streams, flowsheet systems, TEA, LCA and uncertainty studies; installation also documents Graphviz and dependency/build issues. Current setup metadata advertises Python 3.12+ and includes both a `MIT` license field and a University of Illinois/NCSA classifier, whereas the linked upstream LICENSE file identifies the current licence as University of Illinois/NCSA and confines legacy MIT text to old versions. This inconsistency must be resolved against the selected release before shipping.
- **DWSIM 10.2.12** is an external desktop simulator with a cross-platform .NET/Avalonia application and a GPL-3.0 open-source core. Its standalone DTL thermodynamics library has separate LGPL-3.0 terms. Keep it outside the Python wheel/environment and perform licence review before any embedding or redistribution.

## Technical fit by ENERGY-008 need

- **CO2/H2/CO/MeOH high-pressure synthesis mixture:** CoolProp contains relevant pure-fluid models and EOS functionality, but it is not approved as a drop-in replacement for the intended PR78 implementation until the exact component list, mixing rule, binary parameters and phase validation are fixed. No `kij` is defaulted in this migration.
- **Water/steam:** CoolProp includes an IAPWS-IF97 implementation; this is a candidate implementation/reference cross-check once stream pressure/temperature/quality states and interface conventions are fixed. It is not active in the present engine.
- **Methanol-water VLE:** no validated Wilson/NRTL coefficients are present in the project. No library can resolve the absent source data by changing the model implicitly. Candidate package output would still need independent x-y-T/P validation.
- **R-301 kinetics:** Cantera may be useful only after the source reaction mechanism is parameterised for the catalyst and operating range. A gas-phase mechanism is not automatically a heterogeneous catalyst model.
- **Route B:** BioSTEAM is architecturally relevant, but adding it before feedstock assays, gasification yield/energy data and cleanup design would generate invented performance. Its custom-unit-operation support does not itself provide validated conversion/yield data.
- **External process simulator:** DWSIM can be used as an independent simulator for carefully specified unit operations/flowsheets. It should be treated as a separately versioned external calculation tool, with a documented file/API boundary and independent checks, not a source of unquestioned numbers.

## Licence and distribution rule

This migration package does not bundle CoolProp, Cantera, BioSTEAM, DWSIM, REFPROP or any third-party property database. The only runtime requirements are NumPy, SciPy, pandas and Matplotlib. Third-party license and version links are recorded in `licenses/THIRD_PARTY_NOTICES.md`. Reassess all transitive licences and commercial-distribution consequences before shipping a binary or embedding an optional simulator.
