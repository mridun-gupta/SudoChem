# MATLAB Run Results

Prompt 19 exports one unique, non-overwriting run directory here after a MATLAB execution:

`MATLAB/results/<run_id>/`

Expected files include component/element closure CSVs, scenario and sensitivity tables, environmental KPI table, equipment/utility registers, fixture test results, optional XLSX workbook, JSON run summary and a PNG reference-flow chart.

No run-result files are included in this source package because MATLAB/Octave was unavailable in the build environment. Runtime status is `NOT RUN`. The empty results area is intentional; do not populate it with manually copied fixture answers.
