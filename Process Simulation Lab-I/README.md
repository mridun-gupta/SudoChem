# ⚙️ Process Simulation Lab-I

> **Program:** *Integrated Masters of Technology in Chemical Technology*
> **Institution:** *Institute of Chemical Technology, Mumbai – Marathwada Campus, Jalna (MarJ, in short)*
> **Semester:** *5*
> **Status:** 🟡 *Ongoing — lab ends 07.12.2026*

This folder documents my **Process Simulation Lab-I** work — MATLAB (`.m`) simulations of chemical-engineering unit operations and thermodynamic models, with each experiment's write-up, problem sheet, and report.

---

## 📂 Folder Structure

```
Process Simulation Lab-I/
├── 1. Agitator/                                  # Agitation & mixing
├── 2. Adiabatic Rotary Dryer/                    # Drying operations
├── 3. Fugacity Coefficient/                      # Thermodynamic fugacity
├── 4. UNIQUAC Model/                             # Activity-coefficient model
├── 5., 6. Bubble Point, Dew Point/               # VLE flash calculations
├── 7., 8. Absorber, Stripping Unit/              # Absorption & stripping
├── 9. Distillation Column/                       # Distillation simulation
├── 10., 11. VLE, LLE/                            # Vapour/liquid & liquid/liquid equilibria
├── 12., 13. ... LLE Unit, Cooling Tower/         # Multistage extraction + cooling tower
├── 14., 15. SLE, SVE/                            # Solid/liquid & solid/vapour equilibria
├── PSLassignment1/                               # Assignment 1
├── PSLassignment2/                               # Assignment 2
└── README.md                                     # This file
```

Each experiment folder carries its MATLAB source (`.m`), generated write-up (`.md`), outputs (`.pdf`), the issued problem sheet, and the scanned report where applicable. Reference material used lives under each folder's `Sourced references/`.
